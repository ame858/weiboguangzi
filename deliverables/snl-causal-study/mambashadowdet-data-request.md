# MambaShadowDet 实验材料申请

**收件人**　曾天骄老师（tzeng@uestc.edu.cn）

**主题**　申请 MambaShadowDet 论文的 SNL 实验标注与划分

曾天骄老师，您好！

我们正在开展一个本科生视频 SAR 阴影检测研究项目，希望复核贵团队 MambaShadowDet 论文（Remote Sensing, 2025, 17(2), 214）在公开 Sandia 视频上的实验。我们已取得公开的 Eubank Gate and Traffic 视频，也能运行社区标注基线。由于社区标注和论文的评测划分可能有差异，我们希望按论文的口径开展对照。

请问是否方便提供论文实验所用的逐帧目标标注（框或掩膜均可）、训练和验证的原视频帧编号，以及判定正确检测的匹配规则？如果方便分享下载链接或评测脚本，也非常感谢。若完整标注不便共享，帧编号与标注说明也能帮助我们准确对照。材料仅用于学术复核，并会遵守您说明的使用条件及注明来源。

感谢您拨冗阅读！
